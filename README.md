# DEAR MR. ZOU

A Proposal From Class 2603 · 致邹老师：来自2603班的一份特别提案

六章连续展开的静态交互作品，以商务提案为起点，逐渐变成刚刚相识的师生之间的问候。作品没有虚构师生经历，也不需要照片、账号、API、服务器或付费设施。

## 直接预览

`dist/` 已包含完整构建产物。它可以直接放到静态托管服务；资源路径全部为相对路径，兼容 GitHub Pages 的仓库子路径。默认显示英文品牌标题与中文叙事，右上角切换为完整英文叙事。切换保持当前章节与互动状态。

Chrome/Edge 的常规 HTTP(S) 页面是推荐的运行环境。源码 ZIP 中的 `dist/index.html` 也采用传统 script，可在支持本地 HTML 的浏览器中打开；Android 文件管理器的内置预览可能限制脚本，部署后的网址更可靠。
